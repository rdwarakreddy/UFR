Technical Modules

Workshop Categories

Select from our specialized engineering bootcamps tailored for college-level execution.

Embedded Systems & Microcontrollers Hardware Track

Hands-on firmware development using STM32, ESP32, and Arduino platforms. Focuses on bare-metal programming, register mapping, and low-level protocol drivers.

Topics Covered: UART/SPI/I2C protocols, GPIO interrupt service routines, PWM generation, power optimization.
Duration: 2 to 3 Days (16 Hours)
Target Audience: ECE, EEE, Robotics UG/PG
Requirements: Basic C programming knowledge; laptop with IDE installed.
Key Student Outcome Build a Custom Multi-Sensor Telemetry Node
arrow_forward
Autonomous Mobile Robotics (ROS) Robotics Track

Master Robot Operating System (ROS 2) for autonomous navigation, SLAM mapping, sensor fusion, and Gazebo simulation environments.

Topics Covered: ROS 2 Nodes/Topics/Services, LiDAR SLAM, Navigation2 stack, IMU-Odom sensor fusion.
Duration: 3 Days (20 Hours)
Target Audience: CSE, ECE, Robotics, AI/ML
Requirements: Linux/Ubuntu basic commands, Python/C++ fundamentals.
Key Student Outcome Deploy Autonomous LiDAR Navigation Robot
arrow_forward
Edge AI & Computer Vision AI Track

Deploy lightweight neural networks directly onto edge hardware platforms (NVIDIA Jetson / Raspberry Pi) for real-time visual inspection.

Topics Covered: OpenCV pipeline, YOLO object detection tuning, TensorRT optimization, edge inference loops.
Duration: 2 Days (14 Hours)
Target Audience: CSE, Data Science, AI/ML, ECE
Requirements: Python programming; basic machine learning concept exposure.
Key Student Outcome Build Real-Time Vision Tracking System
arrow_forward
Industrial IoT & Cloud Integration Cloud & Systems Track

Connect physical hardware nodes to enterprise cloud infrastructure for real-time data ingestion, monitoring, and automated alerts.

Topics Covered: MQTT/HTTP protocols, AWS IoT Core setup, Node-RED dashboarding, remote actuator management.
Duration: 2 Days (12 Hours)
Target Audience: IT, CSE, ECE, Systems Eng
Requirements: Basic networking awareness; familiarity with JSON structures.
Key Student Outcome Deploy AWS Cloud-Connected Telemetry Node
